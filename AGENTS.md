# Maintenance

- Treat this repository as the canonical source for the resume.
- Keep the Chinese application, Chinese standard, and English versions aligned when shared facts change.
- Preserve model and project details as historical facts; do not replace model names with newer versions unless the work was actually performed.
- Run `make` after each content change and inspect the generated PDFs before committing.
- Commit every completed resume update with a concise message describing the content change.
- Do not commit generated PDFs, TeX intermediates, or proprietary font files.
